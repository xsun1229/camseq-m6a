Round 5 (INLINE library; JLK07=Mfs_NI/RIH014, JLK08=Mfs_LPS/RIH004, JLK09=Mfs_LPS/RIH007) had to be run as two separate pipeline jobs (JLK07 alone, then JLK08+JLK09 together) due to a Snakemake directory-lock conflict, then merged back into one site table (round5_JL_merged) – see Pipeline overview for why. Read-level stats (trimming/mapping/dedup) still live in the two original job directories, so this doc’s MultiQC and read-count sections read from both. See QC – round 3 for the full explanation of the binomial p-value / methylation-ratio sweep used below.

Site calling QC

Swept over binomial p-value cutoff x methylation-ratio (Uncon/Depth) cutoff, with the pipeline’s other two defaults held fixed (min_uncon=1, min_depth=10), focusing on per-sample results for now (no pooled/replicates-merged view). Motif plots show the top 10 motifs by count for both the 5-mer (motif_flanking=2, the pipeline’s own annotation) and the derived +-1nt 3-mer; colors are assigned once per motif string and reused everywhere, so the same motif is always the same color across every plot in this doc.
